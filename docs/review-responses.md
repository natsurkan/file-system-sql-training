# Ответы на замечания

## 1. Индекс `(folder_id, name)`

После партиционирования глобальную уникальность по `(folder_id, name)` по-прежнему проверяет trigger, но я действительно упустил поддерживающий индекс. Добавил обычный индекс `(folder_id, name)` на партиционированную таблицу: PostgreSQL создаёт соответствующие индексы в партициях, поэтому проверки trigger больше не требуют полного просмотра их строк.

## 2. Перенос `materialized_path`

Исправил миграцию партиционирования: добавил `materialized_path` в новую таблицу, перенёс сохранённые значения из старой таблицы и восстановил индекс по этому столбцу.

## 3. Отчёт по годам и месяцам

Переделал отчёт через `crosstab` с динамическим формированием колонок по годам из исходных данных — при появлении нового года править SQL вручную больше не нужно.

## 4. FormattableString и параметры SQL

Добавил выполнение SQL-шаблона из файла через `FormattableString`: его аргументы автоматически преобразуются в `NpgsqlParameter`, поэтому запрос остаётся параметризованным, а дублировать SQL в C# не требуется.
