# Сценарий 2. Полный путь родительских папок файла

## Задача

По `FileId` вывести путь к папке файла и пути всех её родителей до корня.

## Моя логика

    нашли файл

    нашли папку, в которой лежит файл

    поднялись к её parent_folder_id

    нашли родительскую папку

    повторяли это до корневой папки

    из найденных имён построили пути

    вывели путь файла, родителей и корень

## Граничные случаи

    файл находится в корневой папке

    файл находится глубоко во вложенных папках

    файл не найден

## Индексы/производительность

    пока не разбирали
