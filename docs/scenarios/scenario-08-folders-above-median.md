# Сценарий 8. Папки выше медианы вложенных файлов

## Задача

Вернуть все папки, где количество файлов в самой папке и во всей её вложенности больше общей медианы количества файлов по всем папкам.

## Моя логика

    получили список всех папок

    для каждой папки получили список её самой и всех потомков

    нашли файлы этих папок

    посчитали количество файлов для каждой исходной папки

    получили промежуточную таблицу folder_id, folder_name, file_count

    взяли только значения file_count

    отсортировали значения file_count

    передали значения file_count в percentile_cont(0.5)

    получили одну общую медиану количества файлов

    сравнили количество каждой папки с этой медианой

    оставили папки, где file_count больше медианы

## Граничные случаи

    папка без файлов

    папка только с файлами во вложенных папках

    несколько папок имеют одинаковое количество файлов

    ни одна папка не больше медианы

## Индексы/производительность

    пока не разбирали
