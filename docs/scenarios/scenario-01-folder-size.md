# Сценарий 1. Суммарный размер файлов папки

## Задача

Для переданного `FolderId` найти размер всех файлов в этой папке и во всех её вложенных папках.

## Моя логика

1. Передаём в запрос `FolderId` исходной папки.
2. Первый `SELECT` находит эту папку.
3. Рекурсивная часть ищет в `Folders` дочерние папки:

   ```text
   parent_folder_id дочерней папки = id найденной папки
   ```

4. Найденные дочерние папки снова проверяются на наличие своих детей.
5. Когда новых дочерних папок больше нет, рекурсия заканчивается.
6. В `folder_hierarchy` остаются id исходной папки и всех её потомков.
7. Через `JOIN` находим в `Files` файлы, у которых `folder_id` входит в этот список.
8. `SUM` складывает размеры найденных файлов.
9. Если файлов нет, `COALESCE` возвращает `0` вместо `NULL`.

Для `FolderId = 1` результат тестовых данных — `20` байт.

## Граничные случаи

- папка без файлов возвращает `0`;
- файлы только во вложенных папках тоже учитываются;
- неизвестный `FolderId` возвращает `0`.

## Индексы/производительность

Для этого запроса полезны индексы:

```sql
CREATE INDEX ix_folders_parent_folder_id
    ON folders(parent_folder_id);

CREATE INDEX ix_files_folder_id
    ON files(folder_id);
```
