# Сценарий 1. Суммарный размер файлов папки

## Задача

Для заданной папки найти общий размер всех файлов внутри неё и во всех вложенных папках.

## Моя логика

    получили исходную папку

    нашли всех её потомков

    нашли файлы этих папок

    сложили размеры файлов

    если файлов нет, вернули 0

## Граничные случаи

    папка без файлов

    папка с файлами только во вложенных папках

    папка без вложенных папок

## Индексы/производительность

    пока не разбирали
