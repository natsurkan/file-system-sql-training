# Сценарий 9. Materialized Path, индекс и backfill

## Задача

Добавить Materialized Path для папок и файлов, заполнить его для существующих данных и создать индексы.

## Моя логика

    добавили колонку materialized_path в Folders

    добавили колонку materialized_path в Files

    для корневых папок построили путь из '/' и имени папки

    для дочерней папки взяли путь родителя

    добавили к нему имя дочерней папки

    записали готовые пути в Folders

    взяли путь родительской папки для каждого файла

    добавили к нему имя файла

    записали готовые пути в Files

    создали индекс для путей папок

    создали индекс для путей файлов

    выполнили SELECT и проверили полученные пути

## Граничные случаи

    корневая папка

    вложенная папка

    файл в корневой папке

    файл во вложенной папке

    повторный запуск SQL

## Индексы/производительность

    индексы создаются отдельным SQL-запросом
