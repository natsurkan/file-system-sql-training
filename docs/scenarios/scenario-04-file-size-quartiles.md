# Сценарий 4. Квартили размера файлов

## Задача

Для заданной папки и всех её вложенных папок найти первый, второй и третий квартиль размеров файлов.

## Моя логика

    получили исходную папку

    нашли всех её потомков

    нашли файлы этих папок

    взяли размеры файлов

    отсортировали размеры внутри percentile_cont

    получили границу первых 25 процентов

    получили границу первых 50 процентов

    получили границу первых 75 процентов

    вывели Q1, Q2 и Q3

## Граничные случаи

    папка без файлов

    папка с одним файлом

    папка с нечётным количеством файлов

    папка с файлами только во вложенных папках

## Индексы/производительность

    пока не разбирали
