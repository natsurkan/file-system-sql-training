# Сценарий 7. Размеры по годам и месяцам

## Задача

Вернуть таблицу, в которой годы являются колонками, месяцы строками, а в ячейках находится сумма SizeBytes файлов, созданных в соответствующем году и месяце.

## Моя логика

    взяли файлы

    из CreatedAtUtc получили год

    из CreatedAtUtc получили месяц

    сгруппировали файлы по году и месяцу

    сложили SizeBytes внутри каждой группы

    получили промежуточные строки год, месяц, сумма

    развернули годы в отдельные колонки

    оставили месяцы строками

    вывели суммы в байтах

## Граничные случаи

    в месяце нет файлов

    есть файлы только в одном году

    есть файлы в нескольких годах

## Индексы/производительность

    пока не разбирали
