# Сценарий 7. Размеры по годам и месяцам

## Задача

Вернуть таблицу, в которой годы являются колонками, месяцы строками, а в ячейках находится сумма SizeBytes файлов, созданных в соответствующем году и месяце.

## Моя логика

    взяли файлы

    из CreatedAtUtc получили год

    из CreatedAtUtc получили месяц

    сгруппировали файлы по году и месяцу

    сложили SizeBytes внутри каждой группы

    получили промежуточные строки год, месяц, сумма

    развернули годы в отдельные колонки

    оставили месяцы строками

    вывели суммы в байтах

## Запуск динамического отчёта

В консольном тренажёре выбрать сценарий 7 и действие 1. Сценарий устанавливает
функцию из `database/migrations/005_add_year_month_report.sql`, открывает курсор
и выводит все полученные колонки. Конкретные годы в C# не перечисляются.

В SQL-клиенте сначала выполнить миграцию 005, затем целиком следующий блок
в одном соединении:

```sql
BEGIN ISOLATION LEVEL REPEATABLE READ;
SELECT open_year_month_report('year_month_report');
FETCH ALL FROM year_month_report;
COMMIT;
```

Функция один раз группирует файлы по номеру месяца и году во временную таблицу.
Из неё получает отсортированный список годов. Этот список задаёт одновременно
категории crosstab и описание выходных колонок. crosstab размещает готовые суммы,
пустые ячейки заменяются нулём. Названия месяцев выводятся на английском,
порядок месяцев календарный. Числовые суммы сохраняют PostgreSQL-тип numeric.

Вызов рассчитан на отдельную транзакцию отчёта. При COMMIT временная таблица
удаляется, курсор закрывается. Пустой каталог возвращает пустой результат.
Отображаются только месяцы и годы, представленные в данных. Месяц и год
вычисляются в часовом поясе текущего соединения PostgreSQL.
