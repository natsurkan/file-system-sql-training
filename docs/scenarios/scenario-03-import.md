# Сценарий 3. Импорт физической папки через ADO.NET

## Задача

Импортировать учебную физическую папку из sample-data/import-source в таблицы Folders и Files.

## Моя логика

    нашли учебную физическую папку

    обошли её и вложенные папки

    отдельно нашли файлы

    прочитали содержимое файлов

    собрали всё в ImportedFolder

    передали готовую иерархию в DatabaseImporter

    DatabaseImporter открыл connection

    DatabaseImporter начал одну transaction

    создал папку в базе

    получил её id

    сохранил файлы этой папки

    передал id дочерней папке

    повторил сохранение для вложенных папок

    завершил transaction через Commit

    выполнили SELECT из базы

    получили строки с папками и файлами

    собрали из строк новую иерархию

    вывели структуру, восстановленную из базы

## Граничные случаи

    пустая папка

    папка только с файлами

    папка с вложенными папками

    ошибка во время импорта

## Индексы/производительность

    пока не разбирали
