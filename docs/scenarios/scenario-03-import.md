# Сценарий 3. Импорт физической папки через ADO.NET

## Задача

Импортировать учебную физическую папку из sample-data/import-source в таблицы Folders и Files.

## Моя логика

    нашли физическую учебную папку

    обошли эту папку и все вложенные папки

    нашли все файлы

    прочитали содержимое файлов

    собрали найденные папки и файлы в иерархию C#

    передали иерархию в DatabaseImporter

    открыли соединение с PostgreSQL

    начали одну транзакцию

    создали корневую папку

    получили её id

    сохранили файлы корневой папки

    создали вложенную папку

    передали её id для сохранения её файлов

    повторили это для всех вложенных папок

    завершили транзакцию через Commit

    выполнили SELECT из базы

    получили из базы папки и файлы

    заново собрали иерархию из результата SELECT

    вывели физическую иерархию

    вывели иерархию, восстановленную из базы

## Граничные случаи

    пустая папка

    папка только с файлами

    папка с вложенными папками

    ошибка во время импорта

## Индексы/производительность

    пока не разбирали
