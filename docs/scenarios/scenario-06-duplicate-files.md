# Сценарий 6. Поиск файлов-дубликатов

## Задача

Найти файлы с одинаковым содержимым и вывести имя файла и количество его дубликатов.

## Моя логика

    взяли все файлы из Files

    сгруппировали файлы по Content

    посчитали количество файлов в каждой группе

    оставили группы, где файлов больше одного

    соединили найденные группы обратно с Files

    получили имена файлов

    вывели имя файла и количество дубликатов

## Граничные случаи

    дубликатов нет

    два файла имеют одинаковое содержимое

    несколько файлов имеют одинаковое содержимое

    одинаковые имена, но разное содержимое

    разные имена, но одинаковое содержимое

## Индексы/производительность

    пока не разбирали
