# Сценарий 5. Сравнение файлов за сегодня и вчера

## Задача

Для заданной папки и всех её вложенных папок сравнить количество файлов, созданных сегодня и вчера.

## Моя логика

    получили исходную папку

    нашли всех её потомков

    нашли файлы этих папок

    отдельно определили начало сегодняшнего дня по UTC

    разделили файлы на созданные сегодня и вчера

    посчитали количество сегодняшних файлов

    посчитали количество вчерашних файлов

    вычли вчерашнее количество из сегодняшнего

    разделили разницу на вчерашнее количество

    умножили результат на 100

    вывели сегодняшнее количество

    вывели вчерашнее количество

    вывели разницу

    вывели процент изменения

## Граничные случаи

    сегодня и вчера одинаковое количество файлов

    сегодня файлов больше

    сегодня файлов меньше

    вчера файлов нет

    папка без файлов

## Индексы/производительность

    пока не разбирали
